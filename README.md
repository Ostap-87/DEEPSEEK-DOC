# DEEPSEEK-DOC — отчёты в стиле Global Tech Tour

Шесть аналитических отчётов, собранных из Word-исходников в единую вёрстку:
обложка с фотоколлажем, разворот «Главное», альбомная таблица сравнения,
карточки объектов, фото-разворот, выводы.

## Структура

```
build/     движок вёрстки (r_lib.py), сборка (mk.py), утилиты
reports/   контент отчётов — Python-модули со структурированным текстом
fonts/     Inter + Oswald (OFL), только кириллица и латиница
img/pool/  фотографии (Pexels License)
out/       готовые PDF
preview/   обложки в PNG
```

## Как собрать заново

Нужны: Python 3.11+, Google Chrome, pypdfium2 (для превью и проверки страниц).

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install pypdfium2 pillow

python build/mk.py airport out/airport.pdf --preview
```

`mk.py` берёт модуль из `reports/`, собирает HTML в `build/`, печатает PDF
через headless Chrome (`--print-to-pdf`) и по флагу `--preview` раскладывает
страницы в PNG.

## Дизайн-система

- палитра: `#1A73E8` (акцент), `#0B1F3F` (тёмный), `#F1F5FD` (плитки), `#F7F9FC` (зебра);
- шрифты: **Oswald** — заголовки, **Inter** — текст;
- A4, поля 15 мм, подвал с номером страницы, альбомные вставки — через `@page land`;
- компоненты: плитки-метрики, врезка «Итог», блоки «Не подтверждено», таблицы, фото-сетка 2×3.
